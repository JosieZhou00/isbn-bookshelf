# 隐私说明

## 本机书架

本机模式不要求注册。书架数据保存在当前浏览器的 `localStorage` 中，不会由本项目主动上传。清除浏览器网站数据、卸载浏览器或更换设备可能导致数据丢失，因此建议定期导出 CSV。

## 邮箱云端书架

启用 Supabase 后，邮箱用于接收一次性登录链接和识别账号。图书记录保存在部署者自己的 Supabase 项目中。数据库启用了 Row Level Security，每个登录用户只能访问 `user_id` 与本人账号一致的记录。使用 Supabase 默认邮件服务时，邮件只发给项目组织成员地址；若以后面向其他邮箱开放，需要另行配置专用 SMTP 服务。

前端只能配置 Supabase publishable key。`service_role`、secret key、数据库密码和第三方图书接口密钥不得写入前端或提交到 Git。

## 图书查询

未配置聚合后端时，浏览器会把 ISBN 发送到 NeoDB、Google Books 和 Open Library。配置查书 Edge Function 后，浏览器先把 ISBN 发送至部署者的 Supabase Function，再由函数查询 NeoDB、豆瓣或所启用的其他图书数据来源。函数会缓存 ISBN 与公开书目信息；为限制滥用，会对客户端网络标识与浏览器标识加盐哈希后按分钟计数，不保存原始 IP。缓存和限流记录不向浏览器账号开放。

## 导出

CSV 由浏览器在用户设备上生成。文件保存位置由用户选择，项目不会代为保管导出文件。
