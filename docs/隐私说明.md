# 隐私说明

## 本机书架

本机模式不要求注册。书架数据保存在当前浏览器的 `localStorage` 中，不会由本项目主动上传。清除浏览器网站数据、卸载浏览器或更换设备可能导致数据丢失，因此建议定期导出 CSV。

## 邮箱云端书架

启用 Supabase 后，邮箱用于发送一次性验证码和识别账号。图书记录保存在部署者自己的 Supabase 项目中。数据库启用了 Row Level Security，每个登录用户只能访问 `user_id` 与本人账号一致的记录。

前端只能配置 Supabase publishable key。`service_role`、secret key、数据库密码和第三方图书接口密钥不得写入前端或提交到 Git。

## 图书查询

查询图书时，浏览器会把 ISBN 发送到 NeoDB、Google Books 和 Open Library。配置查书 Edge Function 后，ISBN 还会先发送至部署者的 Supabase Function，并可能转发到豆瓣或所启用的其他图书数据来源。各数据来源的准确性、可用性和使用条件由相应服务提供者决定。

## 导出

CSV 由浏览器在用户设备上生成。文件保存位置由用户选择，项目不会代为保管导出文件。
